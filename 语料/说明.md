# 语料（给检索用的句子库）

> 现在目录里有两个文件：`说明.md`（本文件，不会被读进语料）和 `起步.txt`（81 句手写语料）。
> 想加就往新建的 `xxx.txt` 里续，一行一句。

这里放你自己攒的话，程序启动时会**全部读进来**当"参考书"。

## 格式

- 一行一句，像人说的话，最好 10~60 字
- 空行忽略；`#` 开头的行当注释忽略
- 文件名随意，扩展名必须是 `.txt`
- 放多少个文件都行，**不会抢关键词**（这些句子只在被查到时才说话）

## 例

```
我一般十一点睡，早上七点起，中间醒一次。
跑步这件事，前三公里最难，过了就顺了。
光年是距离单位，不是时间单位。
```

## 从哪来

程序旁边那个 `待补语料.txt` 是它自己记的"没答上的话"。
挑有用的，改写成一句完整的话，粘到这里新建的 `xxx.txt`，重启程序就生效。

## 注意

- 越具体越好："番茄炒蛋先炒蛋还是先炒番茄" 比 "做菜" 有用得多
- 别放整段文章，检索是按句找的，长段落会被切碎
