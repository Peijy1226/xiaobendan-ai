小笨蛋 —— 使用说明
========================

【怎么运行】
双击「小笨蛋.exe」即可，不需要装 Python，也不用装任何库。
整个文件夹拷到 U 盘 / 机房电脑都能直接跑（机房重启会还原，程序在 U 盘上就不受影响）。

【功能一览】
- 聊天：离线语料 + 联网「灵光」（DeepSeek）
- 报时 / 天气 / 笑话 / 美食 / 王者荣耀
- 计算与换算：汇率、单位、百分比、日期差、进制、亲戚称谓（点卡片填前缀，补数字回车就算）
- 识图：提取文字、认人、认物、描述穿搭（首次加载模型慢几秒，之后很快）
- 整理助手：桌面 / 下载 / 演示夹 的文件移到回收站（可还原）
- 语音播报：在线合成，用系统自带的播放器放，不需要额外组件
- 打赏 / 壁纸 / 字体大小 / 帮助 / 关于
- 右上角「☰ 功能」或按 F3 展开功能条

【联网（灵光）】
要先自己填一把钥匙才能用（免费的，几分钟）：
  1. 打开 platform.deepseek.com，注册登录
  2. 左边「API keys」→ 创建 → 复制那串 sk- 开头的
  3. 打开程序旁边的「API.txt」，粘在「钥匙=」后面，保存
改完切一下顶栏的「灵光 / 短路」开关立刻生效，不用重启。
不填钥匙也能用，就是纯离线，一样能聊。

【整理助手】
默认关着，要先去功能里把总闸打开。
只认桌面 / 下载 / 演示夹三个文件夹，只把文件移到回收站（能还原），
单次最多 10 个、合计不超过 200 MB。

【常见问题】
1. 杀毒软件报毒：exe 是 PyInstaller 打包，个别杀软会误报，加信任 / 白名单即可。
2. 第一次识图慢：要加载 OCR 模型，慢几秒正常，之后很快。
3. 换壁纸：功能里「壁纸」选图片 / 视频；选过的会记住，下次启动还用。
4. 想恢复默认壁纸：删掉同目录的「壁纸选择.txt」。
5. 语音没声音：确认「语音开关.txt」里 开启=1，且电脑能联网（语音是在线合成）。
6. 换电脑后壁纸没出来：删掉「壁纸选择.txt」，让它重新按本机路径找默认壁纸。

【目录说明】
- 小笨蛋.exe          主程序（双击运行，不需要装 Python）
- 小笨蛋.py           源码（仅源码版有，想改就改这个）
- 打包.spec           重新打包用的配置（仅源码版有）
- 识图引擎.py         独立的识图模块（仅源码版有，主程序不依赖）
- _internal/          运行所需的库、Tcl/Tk、OCR 模型（别删）
- 壁纸/               默认壁纸（xiaobendan.mp4）
- models/             人脸、物体检测模型（别删）
- 素材*.txt、语料/     离线语料（别删）
- 表情/               表情包（离线 / 灵光 两个池子）
- 人设.txt            人设文本（可编辑）
- 灵光开关.txt         联网配置（可编辑，内含钥匙）
- 语音开关.txt         语音播报开关
- 整理助手开关.txt     整理功能总闸
- 壁纸选择.txt         记住上次选的壁纸（自动生成）
- 语音缓存/           合成的语音 mp3（自动生成，可清空）
